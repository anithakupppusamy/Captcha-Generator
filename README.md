# CAPTCHA Generator

A simple and responsive CAPTCHA Generator built using **HTML, CSS, and JavaScript**. The application generates a random CAPTCHA code, allows users to refresh it, and validates the entered CAPTCHA against the generated code.

## 🚀Live Demo
https://anithakupppusamy.github.io/Captcha-Generator/

## 🚀 Features

- Generate random CAPTCHA codes
- Refresh CAPTCHA with a single click
- Validate user input
- Instant success/failure feedback
- Responsive and clean user interface
- Built with pure HTML, CSS, and JavaScript

## ⚙️ How It Works

1. A random 6-character CAPTCHA is generated when the page loads.
2. Users can generate a new CAPTCHA by clicking the refresh button.
3. Enter the displayed CAPTCHA in the input field.
4. Click **Submit Captcha**.
5. The application displays whether the entered CAPTCHA is correct or incorrect.

## 🔧 Installation

1. Clone the repository:

```bash
git clone https://github.com/anithakuppusamy/captcha-generator.git
```

2. Open the project folder:

```bash
cd captcha-generator
```

3. Open `index.html` in your browser.
